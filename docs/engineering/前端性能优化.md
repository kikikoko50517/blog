# 前端性能优化

## externals 提取项目依赖
在 Vue CLI 项目中配置`externals`可以用来排除特定的依赖项，使其不被打包到最终的构建文件中，而是从外部引入。这个配置通常用于那些通过 CDN 引入的库，以减小打包后的文件体积。

![](https://cdn.nlark.com/yuque/0/2024/png/22036110/1725261288461-6290859c-e744-4c49-abfa-065cd83b4ec5.png)

### 为什么需要排除特定的依赖性
+ **减小打包文件体积**：通过将某些依赖（如`Vue、ElementUI`）标记为 `externals`，你可以避免将它们打包到最终的文件中，从而减少打包文件的体积。这些依赖将从外部提供，例如通过 CDN 加载。
+ **避免重复加载**：如果你在多个项目中使用相同的库，并且这些库在 CDN 上已经被加载过，使用 `externals` 可以防止它们在每个项目中都被打包（如`exceljs`），从而避免重复加载。
+ **提高加载速度**：将大型库从打包文件中移除，并使用 CDN 加载，可以加快页面的加载速度，因为 CDN 通常有较快的响应时间和更高的缓存命中率。
+ **减少构建时间**：排除大型依赖可以减少构建时间，因为 Webpack 不需要处理这些依赖的所有代码。

### 项目配置实现
1. 在`vue.config.js`中配置`webpack`

```javascript
module.exports = {
  configureWebpack: (config) => {
    config.externals = {
      'vue': 'Vue',
      'vue-router': 'VueRouter',
      'vuex': 'Vuex',
      'element-ui': 'ELEMENT',
      'lottie-web': 'lottie',
      'exceljs': 'ExcelJS',
    }
  }
}
```

2. 在`index.html`中引入库的CDN地址

```html
<body>
  <script src="https://file.douge.cn/libs/vue/2.7.16/vue.runtime.min.js"></script>
  <script src="https://file.douge.cn/libs/vuex/3.6.2/vuex.min.js"></script>
  <script src="https://file.douge.cn/libs/vue-router/3.6.5/vue-router.min.js"></script>
  <script src="https://file.douge.cn/libs/element-ui/2.15.14/index.min.js"></script>
  <script src="https://file.douge.cn/libs/exceljs/4.4.0/exceljs.min.js"></script>
  <script src="https://file.douge.cn/libs/lottie-web/5.12.2/lottie.min.js"></script>
  <div id="app"></div>
</body>
```

3. 配置`Service Worker`缓存，匹配`.min.js`的文件，缓存到`libs-cache`

```javascript
config.plugins.push(
  new WorkboxPlugin.GenerateSW({
    cacheId: 'app-cache-v3',
    swDest: 'service-worker.js',
    runtimeCaching: [
      {
        urlPattern:
          /^https:\/\/file\.douge\.cn\/.*\.min\.(?:js)$/,
        handler: 'CacheFirst',
        options: { cacheName: 'libs-cache' },
      },
    ],
  })
)
```
